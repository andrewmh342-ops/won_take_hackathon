# 맥락 기반 메뉴 안내 구현 범위

사용자 승인: 2026-10-27. 기존 main 기능과 Chrome 음성 인식을 유지하면서 Seunghyun의 Spring Boot 골조 위에 구현한다.

- 질문·이전 대화·동의한 최근 행동 20건과 실제 메뉴 21개를 백엔드에서 AI에 전달한다.
- AI는 제한 지침 안에서 설명과 메뉴 ID를 스스로 만든다. intents.json 고정 답변을 쓰던 이전 R2 설계를 대체한다.
- 반환할 메뉴는 최대 2개이며 실제 목록 검증을 통과해야 한다. 거래 실행, 확인되지 않은 금액·오류 단정은 금지한다.
- 추가 질문 루프와 실제 상담 시스템 연계는 이번 범위 밖이다. 기존 시연 상담 API는 호환을 유지한다.
- 키 없는 FAKE 모드는 연결 검증용 결정적 응답이다. AI 맥락 이해 능력 검증으로 보고하지 않는다.
- 실제 모드에서 인증·크레딧·모델·시간 초과·형식 오류는 실패로 표시한다. 모의 응답으로 조용히 바꾸지 않는다.
- 테스트는 세션 분리, 순서·대화 보존, 동의 철회, 메뉴 검증, Claude HTTP 요청·실패, 프런트 연결을 대상으로 한다.
- 실제 Claude 평가: 같은 '내역' 질문에 이체·환전 흐름별 적절한 메뉴, 명시 질문 우선, 동의 없는 행동 추론 금지, 범위 밖 질문·지침 변경 유도 거부.
- 추가 승인: 같은 분류의 서로 다른 짧은 방문 흐름을 계기로 AI가 능동 역질문을 생성한다. 말풍선 직전의 실제 방문·기록을 서버 스냅샷으로 보존하고 후속 텍스트·음성 질문에 함께 전달한다. 감지 규칙과 AI의 의미 판단을 구분한다.
